ℹ ABOUT / CARA KERJA

> Semua skor disimpan lewat FLOATING DB — database mengambang berbasis localStorage di browser masing-masing pemain.
> Tanpa backend, tanpa login, tanpa server. Situs 100% statis — cocok untuk VERCEL / GITHUB PAGES.
> Untuk lomba: mainkan di satu perangkat/laptop yang sama (mis. display panitia), semua skor top 10 tiap game akan terkumpul otomatis.
> Butuh leaderboard global antar-perangkat? Sambungkan Floating DB ke Vercel KV / Supabase nanti — strukturnya sudah siap.

🎮 CARA MAIN

> Keyboard: ARROW / WASD, SPACE untuk aksi, R untuk restart.
> HP/tablet: tombol touch muncul otomatis di bawah layar game.
> Game over: masukkan username (maks 12 huruf) untuk masuk leaderboard.
> Username kamu diingat otomatis untuk ronde berikutnya.
